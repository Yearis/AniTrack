# AniTrack 🎌

A modern, responsive anime discovery and tracking web application powered by the **AniList GraphQL API**.

---

## ✨ Features

- **Discover Anime:** Browse curated horizontal carousels of Trending, All-Time Popular, and Highest Rated anime.
- **Search & Filters:** Search anime titles with built-in debouncing, plus filters for Genre, Format (TV, Movie, OVA, etc.), and Airing Status.
- **Detailed Anime View:** In-depth modal with synopsis, studio, release dates, score, character cast & voice actors, related anime, recommendations, and YouTube trailers.
- **Favourites List:** Save your favorite anime locally with persistent storage (`localStorage`).
- **Keyboard Shortcuts:**
  - `Space` — Quick-focus the search bar.
  - `Escape` — Close the anime details view.
- **Dark Theme:** Sleek, modern dark UI designed for easy browsing.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Icons:** Lucide React
- **API:** [AniList GraphQL API](https://anilist.gitbook.io/anilist-apiv2-docs/)
- **Styling:** Custom CSS (Dark Theme)

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yearis/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
